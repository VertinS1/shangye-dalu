# 商业大陆 · 商业模拟挑战赛

一套面向校园商业模拟竞赛（商赛）的在线模拟经营 / 交易系统。全班同学分成若干"公司"，在同一块架空大陆上完成 **原材料采购 → 生产制造 → 交易所挂牌 → 合同谈判 → 消费者路演** 的完整商业闭环，由裁判（组委会）与政府团队共同执掌宏观调控。

纯静态前端（原生 HTML / CSS / JS，零构建、零框架），后端使用 WorkBuddy 云服务（托管 Postgres + 用户认证 + RPC 函数）。

## 玩法概览

- **角色**：制造商（投产研发）、贸易商（全球贸易）、政府（宏观调控）、媒体（行情报道）、组委会（裁判）
- **交易所**：连续撮合 + 五档盘口 + K 线 + 做市商，股票上市（IPO）与企业债发行需组委会审批
- **行情引擎**：价格每几秒自动波动一档（波动率 / 更新间隔 / 持续时长由裁判在控制台设定），支持涨跌停板、大盘熔断、集合竞价；服务器定时任务驱动，无需浏览器在线
- **合同中心**：队际购销合同在线起草 / 签署 / 裁定强制执行
- **破产 / 注销**：裁判可对任意账号宣告破产或注销，对方登录即见全屏红屏警示页
- **衍生品**：锁价合约（期货）、做空机制、强平清扫
- **彩蛋**：内置一个地铁跑酷式小游戏

## 目录结构

```
├── index.html        # 主页面（认证 + 全部视图）
├── app.js            # 核心逻辑（视图 / 交易所 / 合同 / 裁判台…）
├── rulebook.js       # 规则手册（内嵌页面）
├── guide.html        # 新社员注册与开赛指引
├── egg.js            # 彩蛋小游戏（商业大逃亡）
├── styles.css        # 全部样式
├── config.js         # 云服务连接配置（部署前填写）
└── database/
    ├── 01_schema.sql     # 表结构 + 约束 + 序列
    ├── 02_policies.sql   # 行级安全（RLS）策略
    ├── 03_functions.sql  # 全部服务端函数（252 个 SECURITY DEFINER）
    └── 04_seed.sql       # 原材料 / 产品 / 汇率 / 赛制参数种子数据
```

## 快速开始

### 1. 后端初始化

1. 在 WorkBuddy 中为项目开通 **云服务**（云数据库 + 用户认证）；
2. 打开云服务的 **SQL 编辑器**，按顺序执行 `database/` 下的四个文件：
   `01_schema.sql` → `02_policies.sql` → `03_functions.sql` → `04_seed.sql`；
3. ⚠️ **务必修改管理口令**：执行
   `UPDATE wbs_settings SET value = '你的口令' WHERE key = 'judge_code';`
   该口令用于注册「政府 / 裁判」角色，泄露等于把裁判台交出去；
4. （可选）行情自动驾驶已在 `03_functions.sql` 末尾创建 pg_cron 定时任务，若你的数据库不支持 pg_cron 可忽略——行情会在有浏览器在线时照常波动。

### 2. 前端配置

编辑 `config.js`，填入你自己的云服务 `endpoint` 与 `publishableKey`（开通云服务时返回的 publicConfig 里有）。

### 3. 本地运行

纯静态，任意静态服务器即可：

```bash
# 任选其一
python3 -m http.server 8080
npx serve .
```

浏览器打开 `http://localhost:8080`，第一个注册的账号请在「裁判控制台 → 赛程控制」确认拿到 admin 角色；其他同学正常注册即可分到制造商 / 贸易商。

### 4. 上线

- **GitHub Pages**：仓库 Settings → Pages → 选择分支即可（纯静态直接可用，注意 config.js 中的 endpoint 必须允许该域名的跨域访问）；
- 或部署到任意静态托管（Vercel / Cloudflare Pages / 对象存储 + CDN）。

## 裁判开赛速查

1. 裁判台 →「赛程控制」→ 开启财年（可先开试运营财年练手）；
2. 「行情中心」→ 自动波动控制台：调波动率 / 更新间隔 / 持续时长；
3. 「资金调控台」「物资调控台」可给任意队伍发钱 / 发货；
4. 「破产 / 注销管理台」可冻结违规账号（红屏警示，可恢复）。
